## Keðjur sem Tony þekkir

1. **Verðrannsókn:** Black Widow finnur verðmun → Hawkeye athugar innkaup → Captain America notar (eftir `logfraedingur`).
2. **Endurheimt kúnna:** Spider-Man finnur kúnna sem fór → Black Widow segir á hvaða verði → tillaga til Agnars.
3. **Innflutningur:** Hawkeye finnur betri birgi → `endurskodandi` (VSK/tollur) + `logfraedingur` (samningur) → tillaga.
4. **Tilboð á nýjum stað:** Randy Couture greinir teikningu → sendir á Dolph/Terry/Wesley → Tony sameinir.
5. **Nýr kúnni með mörg kerfi:** Spider-Man finnur → Arnold flokkar → Randy sameinar fjölkerfatilboð.

## Reglurnar

- Undiragentar geta ekki kallað á aðra undiragenta. Aðallotan sendir verkefnin.
- Aldrei allt liðið „til öryggis" — aðeins þeir sem þarf.
- Stangist tveir á eru báðar tölurnar sýndar; Tony velur ekki þá þægilegri.
- Allt sem fer út (póstur, auglýsing, pöntun, verðbreyting) er ákvörðun Agnars.
- Útlitsreglan: Joker hannar → Miranda dæmir → Brunastál C ræður.
