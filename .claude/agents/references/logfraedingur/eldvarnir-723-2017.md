# Reglugerð um eldvarnir og eldvarnaeftirlit nr. 723/2017

- **Lagastoð:** 39. gr. l. 75/2000.
- **Staða:** í gildi, síðast breytt 29. okt. 2024 (rg. 1191/2024; áður rg. 1352/2021). Staðfest á island.is 04.11.2026.
- **Hlekkur:** https://island.is/reglugerdir/nr/0723-2017

| Gr. | Efni |
|---|---|
| 3. gr. | Eigandi ber ábyrgðina og „getur ekki takmarkað ábyrgð sína … með samningum“. Viðhald skal vera í samræmi við forsendur byggingarleyfis. |
| 4. gr. | Forráðamaður (t.d. leigutaki) ber ábyrgð á eigin brunavörnum og tilkynnir eiganda um það sem skiptir máli. |
| 6. gr. | Eigandi sér til þess að **aðili með starfsleyfi** (rg. 1067/2011) sinni reglubundnu eftirliti og viðhaldi. |
| 10. gr. | Skjalfesting brunaöryggis (viðhald, þjálfun, innra eftirlit) á að vera aðgengileg eldvarnaeftirliti. Skýrslur okkar eru hluti af henni. |
| 11. gr. | Eldvarnarfulltrúi. |
| 19. gr. | Skoðunarskyld mannvirki: flokkar a, b, c og e minnst árlega; flokkar d og f fjórða hvert ár. |
| 25.–26. gr. | Úrbætur innan setts frests. Eigið eftirlit: skýrsla til slökkviliðs innan 2 vikna. |
