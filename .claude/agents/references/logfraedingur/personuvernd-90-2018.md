# Lög um persónuvernd og vinnslu persónuupplýsinga nr. 90/2018

- **Gildistaka:** 15. júlí 2018. Lögin innleiða reglugerð (ESB) 2016/679 (GDPR). Lesin útgáfa: 158a.
- **Hlekkir:** https://www.althingi.is/lagas/nuna/2018090.html · https://www.personuvernd.is
- Gilda um kúnnaskrá (customers_base, tengiliði), póst (email_digest, Thunderbird), myndir í Vasanum og raddupptökur.

| Gr. | Efni |
|---|---|
| 3.–4. gr. | Orðskýringar og gildissvið. Upplýsingar um tengilið hjá fyrirtæki eru persónuupplýsingar. |
| 8. gr. | Meginreglur: lögmæti, skýr tilgangur, lágmörkun, takmarkaður varðveislutími og öryggi. |
| 9. gr. | Heimildir til vinnslu. Hjá okkur: samningur og lögmætir hagsmunir. |
| **13. gr.** | **Notkun kennitölu** er heimil ef hún á sér málefnalegan tilgang og er nauðsynleg til öruggrar persónugreiningar. Þess vegna fer persónukennitala aldrei í log eða URL. |
| 14. gr. | Rafræn vöktun (myndavélar, ökuritar) aðeins í málefnalegum tilgangi. |
| 23.–25. gr. | Ábyrgð ábyrgðaraðila og innbyggð persónuvernd. **Vinnslusamningar** við vinnsluaðila (Supabase, Netlify, Google, Anthropic, Payday, dkPlus). |
| 26. gr. | Skrá yfir vinnslustarfsemi. Fyrirtæki með færri en 250 starfsmenn eru undanþegin, nema vinnslan sé ekki tilfallandi. Kúnnaskráin er ekki tilfallandi, svo skráin þarf að vera til. |
| **27. gr.** | Öryggi persónuupplýsinga og **tilkynning um öryggisbrest**: til Persónuverndar innan 72 klst. (GDPR 33. gr.). |
| 46. gr. | Stjórnvaldssektir. |
