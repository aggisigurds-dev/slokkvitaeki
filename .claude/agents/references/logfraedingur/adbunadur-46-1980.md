# Lög um aðbúnað, hollustuhætti og öryggi á vinnustöðum nr. 46/1980

- **Gildistaka:** 1. jan. 1981. Lesin útgáfa: 158a.
- **Hlekkir:** https://www.althingi.is/lagas/nuna/1980046.html · https://vinnueftirlit.is
- Gilda um verkstæðið (þrýstihylki, CO₂, duft) og verkstaði Brunahólfs (byggingarvinnustaði).

| Gr. | Efni |
|---|---|
| 13. gr. | Atvinnurekandi tryggir fyllsta öryggi og góðan aðbúnað. |
| 14. gr. | Atvinnurekandi upplýsir starfsmenn um hættur og sér um kennslu og þjálfun. |
| 17. gr. | Þegar fleiri atvinnurekendur starfa á sama vinnustað (t.d. verktakar á byggingarstað) bera þeir sameiginlega ábyrgð. |
| 20.–21. gr. | Verkstjóri er fulltrúi atvinnurekanda í öryggismálum. |
| 26. gr. | Skyldur starfsmanna. |
| 37.–38. gr. | Framkvæmd vinnu; reglugerðir um öryggisráðstafanir. |
| 42. gr. | Vinnustaður skal þannig gerður að fyllsta öryggis sé gætt. |
| **65. gr. / 65. gr. a** | **Skrifleg áætlun um öryggi og heilbrigði** með **áhættumati**. Skyldan gildir óháð stærð fyrirtækis. |
| 79.–80. gr. | Tilkynningar um vinnuslys og atvinnusjúkdóma til Vinnueftirlitsins (vísað til þeirra í 80. gr. a og 81. gr.; frestir og orðalag óstaðfest). |
